دليل نقل وتنسيق بيانات المرضى القدامى (Manual Data Migration)

طريقة تحويل دفاتر العيادة الورقية وملفات الإكسل القديمة إلى ملف جاهز للاستيراد دفعة واحدة.

💡
كيف تضيف جميع مرضاك القدامى بدون كتابتهم مريضاً تلو الآخر؟

إذا كانت لديك بيانات مرضى مسجلة في دفاتر ورقية، أو مفكرة، أو ملفات Excel قديمة، يمكنك تجميعها في جدول إكسل بسيط وحفظه بصيغة CSV لرفعه في ثوانٍ، وسيقوم النظام بإنشاء ملفات كاملة لجميع المرضى تلقائياً مع ترقيم ملفاتهم وحفظ بيانات الاتصال.

1

الخطوة الأولى: فتح ملف Excel أو Google Sheets جديد

افتح برنامج Excel أو جداول بيانات Google. اجعل الصف الأول (الصف رقم 1) خاصاً بأسماء الأعمدة (العناوين Headers)، ومن الصف الثاني ابدأ في كتابة أو نسخ بيانات المرضى.

2

الخطوة الثانية: تقسيم وترتيب أعمدة الملف (Columns Guide)

يتعرف النظام تلقائياً على الأعمدة المكتوبة باللغة العربية أو الإنجليزية. إليك التقسيم النموذجي لكل عمود:

اسم العمود (بالعربي أو بالإنجليزي) الحالة طريقة الكتابة والشرح مثال
Display ID أو رقم الملف اختياري رقم ملف المريض في الدفاتر القديمة (لو تركته فارغاً سيرقمهم النظام تلقائياً) 101
Name أو اسم المريض إلزامي اسم المريض ثلاثي أو ثنائي كامل أحمد محمد مصطفى
Gender أو النوع اختياري اكتب: ذكر أو أنثى (أو Male / Female) ذكر
Age أو العمر اختياري عمر المريض بالأرقام 32
Phone أو رقم الهاتف إلزامي رقم الموبايل الأساسي بدون مسافات (يمنع النظام تكرار نفس الرقم) 01012345678
Phone 2 أو هاتف إضافي اختياري رقم هاتف بديل، أو هاتف ولي الأمر/المنزل 01198765432
Call Preference أو تفضيل الاتصال اختياري اكتب phone1 (للرقم الأول) أو phone2 (للرقم الثاني) phone1
WhatsApp Preference أو تفضيل الواتساب اختياري اكتب phone1 (للرقم الأول) أو phone2 (للرقم الثاني) phone1
Medical Alerts أو التحذيرات الطبية اختياري أي حساسية دوائية أو أمراض مزمنة مفصولة بفواصل سكر، ضغط، حساسية بنسلين
Last Visit أو آخر زيارة اختياري تاريخ آخر زيارة للعيادة بصيغة YYYY-MM-DD 2024-06-15
Notes أو الملاحظات اختياري أي تشخيص، شكوى، خطة علاج سابقة، أو ملاحظات خاصة مريض قديم - جلسة علاج جذور سابقة
Created At أو تاريخ التسجيل اختياري تاريخ فتح الملف لأول مرة (YYYY-MM-DD) 2023-01-10
3

الخطوة الثالثة: خطوة الحفظ بصيغة CSV UTF-8 (حاسمة لظهور اللغة العربية بشكل سليم)

  • في برنامج Microsoft Excel: اضغط File (ملف) ➔ Save As (حفظ باسم) ➔ ثم اختر من قائمة نوع الملف (Save as type): CSV UTF-8 (Comma delimited) (*.csv). (مهم جداً اختيار UTF-8 حتى لا تتحول الحروف العربية إلى رموز غير مفهومة).
  • في جداول Google Sheets: اضغط ملف (File) ➔ تنزيل (Download) ➔ اختر قيم مفصولة بفواصل (.csv).
4

الخطوة الرابعة: رفع الملف وتفادي التكرار التلقائي

اضغط على زر "رفع واستيراد ملف المرضى (CSV)"، سيقوم النظام بقراءة كافة المرضى دفعة واحدة وإضافتهم في قاعدة البيانات. وإذا كان هناك مريض مسجل مسبقاً بنفس رقم الهاتف، سيتخطاه النظام تلقائياً حتى لا يحدث أي تكرار لملفات المرضى القدامى.
